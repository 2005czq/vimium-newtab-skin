# Vimium New Tab Skin

A Catppuccin Mocha skin for `https://vimium.github.io/new-tab/` with a video background,
clock, greeting, and daily quote.

## Setup

```sh
fnm use
pnpm install
pnpm build
```

## Output

Tampermonkey script:

```text
dist/vimium-newtab-skin.user.js
```

Open or import that file in Tampermonkey.
