# Vimium New Tab Skin

A self-use skin for `https://vimium.github.io/new-tab/`.

## Setup

```sh
fnm use
pnpm install
pnpm build
```

## Output

Tampermonkey script:

```text
dist/vimium-newtab-skin.user.js
```

Open or import that file in Tampermonkey.
